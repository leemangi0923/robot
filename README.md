# 로봇 연습실

한국어 DRL 입문용 정적 웹앱. **학습용 가상 실행 · 지원 문법 한정**. 교육용 모델은 Doosan M0609입니다.

## 사용 및 실행

배포된 주소를 브라우저로 열면 별도 프로그램 없이 사용할 수 있습니다. 첫 방문에는 짧은 예제가 자동 실행됩니다. 이후에는 브라우저에 저장한 마지막 예제와 코드가 복원됩니다.

1. 학습 단계 또는 ‘예제 모아보기’에서 예제를 선택합니다. 작성 중 코드는 예제별로 보관됩니다.
2. 숫자를 바꾸고 실행 또는 Ctrl/Cmd+Enter를 누릅니다. 새 실행은 초기 자세에서 시작합니다.
3. 일시정지·계속, 한 문장, 정지, 자세 초기화를 사용합니다. 한 문장은 대입을 평가하거나 한 이동을 끝낸 뒤 멈춥니다.
4. 실행 중 편집기는 시작 시점 코드 사본을 표시하며 읽기 전용입니다. 정지는 현재 자세를 유지하고 자세 초기화는 시작 자세로 돌아갑니다.
5. 파일 도구의 위 화살표는 텍스트 가져오기, 아래 화살표는 DRL 내보내기입니다. 되돌리기 버튼은 예제 원본 복원이며 기존 내용은 localStorage의 해당 예제 `-backup` 항목에 보관합니다.
6. 좁은 화면은 코드/3D 탭으로 전환합니다. 3D 드래그 회전, 스크롤 확대, 시점 초기화를 지원합니다.

## 정적 배포

루트의 `index.html`이 진입점입니다. 이 저장소의 정적 파일을 GitHub Pages, Netlify, Cloudflare Pages 등 정적 호스팅의 문서 루트에 업로드합니다. 서브 경로 배포도 상대 경로로 동작합니다. 빌드 단계·백엔드·회원가입 구현·Python·ROS가 필요 없습니다. Three.js 및 OrbitControls는 로컬에 포함되어 있습니다. Google Fonts는 선택적 글꼴 요청이며 실패하면 시스템 글꼴을 사용합니다.

로컬 확인 예: `npx serve .` (Node.js 필요). `file://`로 직접 열면 모듈 및 Worker가 제한되므로 HTTP로 서비스하세요. MIME은 `.js`를 JavaScript로 제공해야 합니다. WebGL 및 ES Module Worker를 지원하는 최신 브라우저를 사용하세요. 브라우저 저장 공간이 차단되면 자동 저장 상태에 경고가 표시됩니다.

GitHub Pages는 Settings → Pages → Deploy from a branch에서 `main` 브랜치와 `/(root)`를 선택해 배포할 수 있습니다. 호스팅 공개 설정은 별도로 선택합니다. 호스팅과 학생의 코드 평가 사이에 서버 호출이 없습니다. 학생 코드는 로컬 브라우저에서만 처리하며 브라우저 API·네트워크·파일 API를 사용자 언어에 노출하지 않습니다.

## 소스 구조

- `index.html`, `styles.css`: 접근 가능한 한국어 UI와 반응형 레이아웃
- `js/editor.js`: 줄 번호, 문법 강조, 편집·강조 줄 동기화
- `js/parser.js`: 토큰화, 표현식 AST, 들여쓰기 블록 AST
- `js/runtime.js`: 허용 AST 평가, 오류·이벤트·모션 계획 생성
- `js/worker.js`: 코드 평가와 IK 경로 계산의 Worker 격리
- `js/robot.js`: URDF 체인, FK, 수치 IK, 경로 보강, 시간 프로파일
- `js/scene.js`: Three.js 단순 형상 로봇·작업대·좌표축·경로·목표 렌더링
- `js/app.js`: 실행 상태, 재생 배율, 단계별 진행, 파일/저장/학습 흐름
- `js/examples.js`: 6단계 초보 예제와 수정하지 않은 파레트 원문
- `tests/core.test.js`: Node 내장 계산 테스트. `tests/ui.test.js`: jsdom 기반 DOM·상태 및 실제 Worker 테스트. 개발 검증은 `npm ci` 후 `npm test`로 실행

`eval`, `Function`, JavaScript 소스 변환을 사용하지 않습니다. 파서가 만든 AST를 제한된 환경의 명시적 연산으로 평가합니다. 정지·초기화·새 실행은 Worker를 종료하고 실행 ID를 증가시켜 이전 결과를 무시합니다.

## 지원 문법표

| 구분 | 지원 |
|---|---|
| 값과 연산 | 유한 숫자, 변수, 대입, 괄호, 단항 +/−, + − * / % //, == != < <= > >= |
| 리스트 | 생성, 리스트 * 정수, for 리스트 반복, 정수 인덱스 읽기/대입, Python식 음수 인덱스 |
| 제어 | range(stop), range(start, stop), for, 들여쓰기 if/else, 값1 if 조건 else 값2 (선택 분기만 평가) |
| 기타 | # 주석, 한 줄 짧은 문자열, tp_log("메시지"), wait(초) |
| 제외 | while, 사용자 함수, import, 여러 줄 문자열, 속성 접근, 브라우저/파일/네트워크 API, 기타 Python/DRL 문법 |

`range`의 step 인수, 논리 연산자, 슬라이스, 증강 대입은 지원하지 않습니다. `wait(1, 0)`은 `wait(1.0)` 수정 안내를 표시합니다. 문자열은 로그용이며 숫자 연산에서 허용하지 않습니다.

| 명령 | 웹앱의 지원 규칙 |
|---|---|
| `posx(X,Y,Z,A,B,C)` / `posx([숫자6개])` | 자세는 별도 태그로 관리하여 자세 리스트와 구분. XYZ mm, ABC °, 오일러 Z–Y′–Z″ |
| `trans(p, delta, ref=DR_BASE, ref_out=DR_BASE)` | 새 자세 생성, 입력 불변. 베이스 XYZ 변화만 지원, 회전 delta는 모두 0. 인수 생략도 웹앱에서는 DR_BASE. 실제 문서의 ref 기본값은 None, ref_out은 DR_BASE로 구분 |
| `movel(p, vel=…, acc=…, ref=DR_BASE)` | 베이스 기준 절대 목표, 방향 유지, 정지→정지 TCP 직선. vel mm/s, acc mm/s². 양수 스칼라 필수. vel ≤ 2,000, acc ≤ 10,000은 웹앱 계산 제한이며 장비 사양 아님 |
| `wait(초)` | 숫자 하나, 0~60초 |

블렌딩, 상대 이동, `time`, 배열형 속도/가속도, 다른 좌표계, 방향 변화 이동은 오류를 표시합니다. `trans`는 위치 인수 ref/ref_out도 허용하며 중복 인수는 거부합니다. 전체 DRL을 재현하는 엔진은 아닙니다.

계산 제한: 소스 60,000자, 리스트/range 1,000개, 총 for 반복 1,000회, 실행 문장 5,000개, AST 평가 20,000회, 모션 300개, 경로 표본 20,000개, IK/경로 예산 250,000회, 계산 시간 15초. 파싱 오류도 Worker 안에서 처리합니다.

URDF 위치 m에 1,000을 곱해 계산 mm로, URDF rpy와 관절각은 rad로 유지합니다. DRL 방향은 °에서 rad로 변환해 Rz(A) Ry(B) Rz(C)를 구성합니다. 화면은 m, Z-up이며 계산 위치를 1,000으로 나눕니다. 원점·회전축·관절 순서·각도 한계는 포함 URDF의 값을 그대로 사용합니다.

초기 TCP: `[322.54,422.29,278.28,180,-90,0]`. 초기 관절각 °: `[63.7367,25.6613,102.3470,-106.8982,69.5716,-48.8997]`. FK 위치 오차 **0.000368218mm**, 방향 오차 **0.000000395934rad**로 확인했습니다.

모션은 최대 2mm 간격 TCP 직선 표본을 만들고 직전 해를 seed로 수치 감쇠 최소제곱 IK를 풉니다. 수렴 기준 위치 <0.004mm, 방향 <0.00004rad. 매 해의 URDF 각도 한계를 확인합니다. 표본 사이 관절 선형 보간의 ¼·½·¾ 위치/방향을 FK로 검사하고, 0.05mm·0.0005rad 또는 관절 변화 0.025rad 기준을 벗어나면 재귀적으로 표본을 추가합니다. 렌더링도 같은 관절 보간을 사용합니다. 이산 표본 기반 교육용 검사이며 연속 구간 전체의 수학적 보증은 아닙니다.

경로 해가 없으면 해당 줄과 **‘교육용 모델에서 경로 해를 찾지 못함’**을 표시하고 계획 전체를 재생하지 않습니다. 관절각을 갑자기 다른 해로 바꾸지 않습니다.

## 시간

매 구간은 정지에서 출발해 정지합니다. 거리 d, 속도 v, 가속도 a에 대해 peak=min(v,√(da)), 가속 시간 peak/a, 등속 시간 max(0,(d−peak²/a)/peak)로 계산합니다. 이동 중 표시 위치는 이 프로파일의 누적 거리로 표본을 조회합니다. 0.5×·1×·2×는 화면 시간 배율이며 코드의 vel·acc와 프로그램 시간을 바꾸지 않습니다.

10mm, acc=100에서 vel=10의 시간은 **1.1초**, vel=100은 **0.632455532초**입니다. 후자는 peak≈31.6228mm/s인 삼각형입니다. acc=400이면 **0.316227766초**입니다.

### 실제 수행한 DOM·Worker 자동 검증

실제 `index.html`과 `app.js`를 jsdom에 로드하고 Node Worker 어댑터로 실제 `worker.js`를 실행했습니다. 렌더링을 대신하는 스텁으로 경로 계산을 바꾸지 않았습니다.

- 첫 방문 자동 실행, 숫자 편집 후 다음 실행 목표 변경.
- 대입문 뒤 멈춤, movel 완료 뒤 다음 문장 앞에서 멈춤.
- 일시정지 중 시간 고정, 계속, 2× 재생 속도와 코드 vel·프로그램 시간 분리.
- 정지 시 자세 유지, 초기화 시 초기 TCP 복귀.
- 파레트 실행 줄·i·선택 칸·목표 좌표 일치.
- 예제 전환 후 작성 코드 보존, 같은 저장소로 앱 모듈을 재생성해 코드 복원.
- 과도한 range 거부, 계산 중 정지 시 Worker 종료 및 늦은 결과 무시.

### 브라우저·시각 검증 한계

관리형 미리보기는 relay 포트 연결 시간 초과로 시작되지 않았습니다. 배포 자체는 Sites 성공 응답으로 확인했습니다. 클라우드 브라우저는 URL 요구사항을 읽지 못해 사이트에 진입하지 못했습니다. 전체 데스크톱 캡처는 다른 앱의 비공개 내용 노출 우려로 자동 승인 검토에서 거절되어 수행하지 않았습니다. 따라서 **WebGL 실제 렌더링·마우스 시점 조작·반응형 화면의 시각 확인은 미완료**입니다. jsdom 테스트에는 WebGL 컨텍스트가 없으며 이 한계를 그래픽 검증 통과로 표현하지 않습니다. 실제 파일 선택/다운로드 브라우저 동작도 추가 확인이 필요합니다.

현재 호스팅은 소유자 비공개입니다. 학생이 로그인 없이 접근하는 공개 호스팅은 별도 공개 승인이 필요합니다. 정적 소스를 다른 정적 호스팅에 그대로 배포할 수 있습니다. 자동 테스트 통과를 실제 제어기 검증으로 간주하지 않습니다.
